# قعدة آخر واحد

12 لعبة إقصاء للقعدة. كل واحد بيلعب من موبايله، وبكل لعبة اللاعبين بيطلّعوا بعض لحد ما يضل آخر واحد.
إعداد م. إياد حلوبي.

## الألعاب
شدّ الحبل · الجزيرة · حجرة ورقة مقص · الدفش · القنبلة · المزاد الأخير · الكاوبوي · معركة المخدّات · تخليص · النفخ · حرب الشحاطات · الدبكة

**اختيار الألعاب:** الريس بيشيل من القائمة اللي ما بدو ياها، و«مرّر» بتشيل اللعبة وبيلفّ الدولاب على غيرها.

**النقاط بكل لعبة:** الأول 5، التاني والتالت 3، من الرابع للسادس 1، والباقي 0. واللي بيطلعوا سوا بيتقاسموا نقاط مراكزهن.

## الرفع على GitHub و Render
1. ارفع كل ملفات هالمجلد على مستودع جديد بـGitHub (بدون `node_modules`).
2. من Render اختار **New → Blueprint**، واربطه بالمستودع.
   Render بيقرا ملف `render.yaml` لحاله وبيولّد مفتاح الإدارة `ADMIN_KEY`.
3. بعد ما يخلص البناء، افتح الرابط اللي بيعطيك ياه Render.

إذا بدك تعملها يدوي بدل الـBlueprint: **New → Web Service**، وبتحط:
- Build Command: `npm install --omit=dev`
- Start Command: `node server.js`

## صفحات إضافية
- الإحصائيات: `/stats`
- الإدارة: `/admin?key=المفتاح` (المفتاح موجود بـRender ← Environment ← `ADMIN_KEY`)

## تشغيل محلي
```
npm install
npm start
```
وبعدين افتح `http://localhost:3000`.

> ملاحظة: لعبة النفخ بتحتاج إذن المايك، والمتصفح ما بيعطيه إلا على رابط `https` (Render بيأمّنه لحاله).
